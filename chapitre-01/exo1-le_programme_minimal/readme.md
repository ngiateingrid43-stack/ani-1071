# C1-Exo1-main — Affichage nom et ville

## Description

Programme C++ qui affiche sur la sortie standard :
1. Le nom de l'auteur
2. La ville de résidence de l'auteur

Chaque information est affichée sur une ligne distincte.

## Prérequis

- Un compilateur compatible C++17 (ici `clang++`)

## Compilation

```bash
clang++ -std=c++17 -Wall c1-exo1_main.cpp -o programme
```

- `-std=c++17` : utilise la norme C++17
- `-Wall` : active les avertissements du compilateur
- `-o programme` : nomme l'exécutable généré `programme`

## Exécution

```bash
./programme
```

YAOUNDE
